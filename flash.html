ESP-SDR firmware installer

Serial-viewer profiles require a 2 MBaud UART adapter. The S31 Ethernet / USB profile for SoapyESPSDR uses 115200 baud for flashing; samples travel over Ethernet or its separate native high-speed USB port.

Flash any supported chip using an on-board or external USB-to-UART adapter. Built-in USB Serial/JTAG is available only on some chips, including ESP32-C5, ESP32-C6, ESP32-C61, ESP32-S3 and ESP32-S31. For serial-viewer firmware, USB Serial/JTAG carries I/Q faster than an external UART adapter. The S31 SoapyESPSDR profile uses a separate native high-speed USB connector for streaming; flash it through USB Serial/JTAG or UART.

Before connecting

  1. Open this page in desktop Chrome, Edge, or Firefox.
  2. Choose the firmware profile below, attach the device, then select Connect device. If it cannot enter flashing mode, unplug it, hold BOOT while reconnecting, release BOOT and try again.

Installing replaces the current firmware and partition table. Choose a firmware image matching your ESP32 chip.

Available ESP-SDR firmware

In addition to the ESP-WebSDR browser interface, ESP32-S3 supports I/Q streaming over native USB at 250 kS/s (8-bit), 125 kS/s or 62.5 kS/s (16-bit) with esp-sdr-bridge ↗ for desktop SDR software such as SDR++ and SDR#. See the bridge project for setup instructions.
