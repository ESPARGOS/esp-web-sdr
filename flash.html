ESP-SDR firmware installer

UART flashing requires 2 MBaud, the speed used by ESP-WebSDR. If your adapter cannot use this speed, choose a different dev kit.

Flash any supported chip using an on-board or external USB-to-UART adapter. Built-in USB Serial/JTAG is available only on some chips, including ESP32-C5, ESP32-C6, ESP32-C61, ESP32-S3 and ESP32-S31. When your board exposes this native USB port, use it for faster I/Q transfers than an external USB-to-UART adapter.

Before connecting

  1. Open this page in desktop Chrome, Edge, or Firefox.
  2. Attach the device, then select Connect device. If it cannot enter flashing mode, unplug it, hold BOOT while reconnecting, release BOOT and try again.

Installing replaces the current firmware and partition table. Choose a firmware image matching your ESP32 chip.
